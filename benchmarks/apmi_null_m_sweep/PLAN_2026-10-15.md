# Staged exact-m AP-MI null calibration

Authorized on 2026-10-15 after discussion of provisional TF p=0.001 and SIG
p=0.0005 operating probabilities. These are exploratory operating settings,
not biological optima or FDR guarantees. No engine defaults are changed by
this study. The user hopes the sweep can finish before 23:00 America/New_York
today; runtime must be measured before launching the full sweep.

## Frozen scientific design

- Use the existing production-shared SJARACNe AP-MI null generator, SHA256
  `08224b6b20e29628be6d89d22eb7e355f8c6a05623e06f801fae5347a70a7f18`.
- Keep the kernel, unique-ordinal-rank policy and Npar=40 fixed.
- All fitting and validation data are synthetic independent rank permutations.
  No BRCA100 or DREAM5 expression or reference-edge labels enter fitting.
- Timing pilot: m=30, 300, 1000; 200,000 draws per m, sequentially. These draws
  measure runtime only and are not production fitting or validation data.
- Stage 1 anchors: m=30, 50, 80, 90, 100, 150, 300, 1000.
- Stage 2 actual DREAM5 counts: m=644, 516, 725. These are exact observation
  counts, not percentages. No interpolation or nearest-neighbor substitution.
- Each production m uses 5,000,000 fitting draws and a separate 5,000,000
  validation draws. Use fresh streams, not the previously examined historical
  calibration draws. Base seeds: fit=20261015, validation=20261016, with the
  existing calibrator's per-m and validation-stream offsets.
- GPD primary tail threshold q=0.995; require at least 20,000 strict primary
  exceedances. Check sensitivity at q=0.9925, 0.995, 0.9975, requiring all three
  valid fits and relative cutoff range <=10%.
- Requested probability support: [0.0005, 0.001]; model default/minimum
  probability=0.0005. Stability is evaluated at 0.0005, not 1e-7.
- Held-out acceptance checks: p=0.001 and 0.0005, preserving the existing
  99% per-model family-confidence setting and conservative family size 10.
  Each point therefore retains its 99.9% Clopper-Pearson interval. This is not
  a claim of simultaneous 99% coverage across every m in the sweep.
- Preserve the existing fail-closed support, schema, seed, provenance and
  independent-validation checks. A diagnostic rejected fit is a legitimate
  completed result, not grounds to relax checks or rerun until accepted.

The legacy calibrator has hard-coded `1e-7` text in its CSV/report descriptions.
Its raw reports must be retained unchanged, but the new summary must label the
actual requested default probability 0.0005 and not repeat that stale heading.

## Execution gates and deadline handling

1. Verify executable/source hashes, dependencies and resources; run the timing
   pilot before committing to production draws.
2. Use measured generation rates to estimate stage runtimes, including margin
   for fitting, validation, WSL and parallel contention. No unmeasured runtime
   guarantee. If the complete sweep is unlikely to finish by 23:00, report that
   promptly; do not reduce simulation counts or weaken gates to meet the time.
3. Run Stage 1 with bounded concurrency (maximum 12 workers). Keep independent
   per-m directories, commands, timings, metadata, logs, hashes and statuses.
4. Run Stage 2 if the timing/resource gate permits it. Technical failures at one
   m do not erase its evidence or prevent diagnostics at other predeclared m.
   No inference about the best biological network follows from passing gates.
5. Validate all completed artifacts and aggregate GPD parameters, cutoffs at
   both operating probabilities, cutoff sensitivity, held-out exceedance rates
   and intervals, and empirical fit-stream quantile diagnostics. Do not use the
   validation stream to refit or select tail thresholds.
6. Preserve original raw streams locally under ignored runs/. Publish only
   compact reports, plots, accepted models and provenance. Do not overwrite
   prior calibration evidence or install models as engine defaults.

Small m can yield unsuitable or invalid GPD fits; report that honestly. A model
fit or calibration rejection is distinct from a corrupted/incomplete native run.
Any interpolation across m or new global default policy requires separate work.
